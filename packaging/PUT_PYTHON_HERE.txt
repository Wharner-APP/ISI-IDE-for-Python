ISI IDE for Python - bundled interpreter folder
===============================================

Place your Python 3.14 distribution in this folder so that the interpreter is at:

  Windows:       <this folder>\bin\python.exe
  Linux / macOS: <this folder>/bin/python3

For example:
  C:\Program Files\Wharner APP\ISI IDE for Python\Python 3.14\bin\python.exe

ISI IDE uses this interpreter by default. You can choose another one at any time in
Tools > Settings > Python interpreter.
